# Coding Style Rules

- **Clean & Human-Readable Code**: Write clear, well-structured TypeScript with consistent formatting and descriptive variable naming.
- **DRY Principle (Don't Repeat Yourself)**: Never duplicate code. Extract repeated logic (such as API calls, coordinate conversions, unit formatting, or event handlers) into standalone, reusable helper functions.
- **Modular Components**: Keep components focused on a single responsibility, delegating heavy calculations and state utilities to helper modules in `/src/utils`.
